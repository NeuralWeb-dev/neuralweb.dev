NeuralWeb

The graphical interface, the Internet and mobile each changed how people interact with computers, and each was followed by a rewrite of most of the software in use: desktop applications, then websites, then apps. AI appears to be the fourth such change.

So far it has mostly produced new applications, chatbots in particular, rather than changes to existing sites, applications and data. We expect the Web to change as well.

NeuralWeb is a small group working on ideas and open source tools related to this. Each project on the left has a running instance, a design document and source code.
